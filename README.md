# SmartStock
O SmartStock é um sistema desenvolvido em Java que tem como objetivo facilitar o gerenciamento de produtos e a visualização de estoques de estabelecimentos comerciais. A plataforma funcionará como um catálogo digital, semelhante a um cardápio virtual, no qual os proprietários poderão cadastrar seus produtos, informar preços e controlar as quantidades disponíveis em estoque. Por meio do sistema, os clientes poderão consultar os produtos disponíveis e visualizar suas respectivas informações, facilitando o processo de escolha e compra. O principal propósito do SmartStock é oferecer praticidade, organização e acessibilidade, por meio de uma interface intuitiva e de fácil utilização, inclusive para pessoas com pouco conhecimento em tecnologia.
